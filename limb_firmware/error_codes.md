# Ninelives Error & Telemetry Catalog
**Architecture Version:** v1.0+ | **Target:** Core 0 (RP5) & Core 1 (RP2040/RP2350)

This catalog defines the standardized logging subsystems, priority levels, and exact telemetry messages generated by the Ninelives SCADA architecture.

---

## 1. Subsystem Tags & Severity Matrix

The logging system routes messages using a 3-character Subsystem Tag. Severity levels map directly to the system's Safety Gradient and determine UI/Alarm routing.

| Category | Tag | CRIT | ERR | WARN | INFO | DBG | Description |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: | :--- |
| **System** | `SYS` | 11 | 2 | 3 | 7 | 0 | Kernel, Boot, Watchdog, Memory, File I/O |
| **Network** | `NET` | 2 | 2 | 5 | 0 | 0 | UART, MTIP Protocol, Handshakes, CRC |
| **Actuators**| `ACT` | 2 | 7 | 3 | 7 | 4 | Motors, Solenoids, Drivers, Safety Stops |
| **Sensors** | `SEN` | 0 | 5 | 5 | 8 | 0 | I2C Bus, Drivers (MPU/TSL), Scanning |
| **PIO/Tach** | `PIO` | 0 | 2 | 0 | 1 | 0 | Pulse Counting, State Machines |
| **Power** | `PWR` | 1 | 0 | 0 | 0 | 0 | Voltage Monitoring, Brownouts |
| **Config** | `CFG` | 0 | 1 | 2 | 1 | 0 | JSON Parsing, Parameter Tuning |
| **OTA** | `OTA` | 0 | 5 | 4 | 3 | 1 | Firmware Updates, File Writing |
| **Tester** | `TST` | 0 | 1 | 1 | 3 | 0 | Hardware Validation Scripts |
